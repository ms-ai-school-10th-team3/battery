# 🔋 AI 기반 이차전지 외관·CT 이미지 불량 검출 시스템

> 본 프로젝트는 Microsoft AI School 미니 프로젝트로 진행 중인 AI 기반 배터리 품질검사 시스템입니다.

---

## 📌 프로젝트 소개

본 프로젝트는 이차전지 생산 및 신뢰성 평가 과정에서 수집되는 **외관 이미지와 CT 이미지**를 AI로 분석하여, 배터리의 정상/불량 여부와 결함 유형, 위험도를 판단하는 품질검사 지원 시스템입니다.

현재는 **CT 이미지를 활용한 CNN 기반 정상/불량 분류**를 중심으로 구현하고 있으며, 향후 외관검사 결과와 CT 내부검사를 연계하여 검수자가 불량 가능성이 있는 배터리를 빠르게 확인할 수 있도록 하는 것을 목표로 합니다.

---

## 🎯 프로젝트 목적

이차전지 내부 결함은 배터리의 안전성과 성능 저하로 이어질 수 있습니다.  
특히 CT 이미지를 사람이 직접 확인하는 방식은 시간과 비용이 많이 들고, 검사자의 숙련도에 따라 판단 결과가 달라질 수 있습니다.

본 프로젝트는 AI 모델을 활용하여 CT 이미지의 정상/불량 여부를 자동으로 분류하고, 검사 결과를 웹 화면에서 확인할 수 있도록 하여 품질검사 업무의 효율성을 높이는 것을 목표로 합니다.

추가적으로 외관검사 결과에서 이상이 감지된 배터리를 CT 내부검사 대상으로 분류하고, 검사 결과를 보고서 및 이력으로 관리할 수 있는 시스템으로 확장하는 것을 목표로 합니다.

## 👥 사용 대상자

본 시스템의 주요 사용자는 **배터리 기업의 품질검사 담당자 및 검수 파트 담당자**입니다.

| 사용자 | 설명 |
|---|---|
| 품질검사 담당자 | 생산된 배터리의 정상/불량 여부를 확인하는 실무자 |
| 검수 파트 담당자 | 외관검사 및 CT 검사 결과를 확인하고 검사 이력을 관리하는 담당자 |
| 신뢰성 평가 담당자 | 충·방전 테스트 전후의 내부 구조 변화를 비교하는 담당자 |
| 생산 공정 관리자 | 공정 세팅 상태와 불량 발생 흐름을 파악하는 관리자 |

## 🏭 사용 상황

### 1. 신제품 양산 초기

신제품 배터리를 본격적으로 대량 생산하기 전, 무작위 샘플 검사를 통해 공정 세팅이 안정적으로 이루어졌는지 확인합니다.

- 외관 불량 여부 확인
- 내부 구조 이상 여부 확인
- 전극 휨 여부 확인
- 공정 세팅 문제 가능성 확인
- 위험도 수준 판단

---

### 2. 신뢰성 평가

배터리를 수백 회 충·방전 테스트하기 전과 후의 CT 이미지를 비교하여 내부 구조 변화를 확인합니다.

- 전극 휨 변화 확인
- Porosity 변화 확인
- 내부 손상 여부 확인
- 구조적 변형 여부 확인
- 테스트 전후 위험도 변화 확인

---

### 3. 생산 라인 품질검사

생산 라인에서 촬영된 배터리 이미지를 AI가 분석하고, 이상이 감지된 배터리를 검수자가 추가 확인할 수 있도록 지원합니다.

- 생산 라인 샘플 검사
- 외관 이상 여부 확인
- CT 내부검사 필요 대상 분류
- 검사 결과 이력 관리
- 불량 발생 흐름 파악

## 🧠 AI 모델 기능

### CT 내부검사 AI

CT 이미지를 기반으로 배터리 내부의 정상/불량 여부를 판단합니다.

예측 결과 예시:

```json
{
  "status": "defective",
  "defect_type": "porosity",
  "risk_level": "high",
  "confidence": 0.88,
  "inspection_time": "2026-05-13 14:42"
}
```

---

### 외관검사 AI

배터리 외관 이미지를 기반으로 정상/불량 여부와 외관 결함 유형을 분류합니다.

예측 결과 예시:

```json
{
  "status": "defective",
  "defect_type": "scratch",
  "risk_level": "medium",
  "confidence": 0.91,
  "inspection_time": "2026-05-13 14:30"
}
```

---

## 🚨 위험도 기준

| 위험도 | 설명 | 처리 방식 |
|---|---|---|
| Low | 경미한 결함 또는 관리 가능 수준 | 일반 관리 |
| Medium | 추가 검토가 필요한 결함 | 검수자 확인 필요 |
| High | 즉시 확인 또는 공정 정지 검토가 필요한 결함 | 내부검사 권장 또는 즉시 알림 |
